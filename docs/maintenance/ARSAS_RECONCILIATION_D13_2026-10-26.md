## 2. P0 code problem: retired post-Write inspection overrides new connection

D12 introduced **detached read-only MMS control inspection** and `Iec61850ControlInspectionPublication.TryApply` on caller's GUI synchronization context, preventing late native tasks holding WPF's mutable `SignalDefinition`. **But that alone was incomplete**:

- `MainWindow.xaml.cs:ReinspectConfiguredControlAsync` awaited facade typed inspection and used `device.LiveValues.Association` to check a saved `writeAssociation` only **after await**.
- The post-Write caller's `catch(OperationCanceledException)` and `catch(Exception)` unconditionally called `signal.ClearLiveControlAuthority()` and reset `ControlModelText`, including if old association had been torn down and a new one already installed/revalidated the same control.
- Further **TOCTOU**: the D12 facade could **publish native inspection capabilities onto the GUI first**, then the post-Write caller sees that its historical model epoch no longer matches. The old caller-only check was too late to prevent a changed live model on the same MMS association from being overwritten.
- This is a testable mutable-authority correctness hazard, **not proof of misoperation on any actual relay**.
