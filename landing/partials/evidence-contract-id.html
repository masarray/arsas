Kontrak evidence

Simpan observasi bersama konteks yang membuatnya bisa direview.

ARSAS memperlakukan data engineering sebagai evidence, bukan sekadar output layar. Field yang tersedia bergantung pada workflow, tetapi source dan acquisition context harus tetap terlihat ketika memang tersedia.

Apa?Signal, event, packet, file, model atau hasil command
Dari IED mana?Identity device, endpoint dan konteks project
Kapan?Waktu IED, waktu protokol atau receive/capture time ARSAS ketika tersedia
Quality / state?IEC quality, event state, sequence state atau result status ketika source menyediakannya
Diperoleh bagaimana?Discovery, MMS read, Reporting, capture GOOSE/SMV, file service atau control workflow
Tidak mengarang kepastian.Tidak semua workflow mempunyai semua field. ARSAS harus menjaga apa yang benar-benar tersedia, menunjukkan acquisition path dan membuat konteks yang hilang tetap eksplisit—bukan membuat proof sintetis.Review batas engineering →
