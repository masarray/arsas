ARSAS adalah aplikasi Windows gratis untuk pengujian relay IEC 61850.

01Pilih sumber

Klik Add IED, lalu pilih IP live atau file SCL.

Gunakan Discover IED by IP untuk relay yang dapat dijangkau. Gunakan Open SCL / CID / ICD untuk memeriksa model vendor atau project secara offline; IID dan SCD juga didukung oleh workflow SCL.

02Bangun model

Masukkan IP relay dan jalankan Smart Discovery.

ARSAS terhubung melalui IEC 61850 MMS pada port 102, membaca identity IED yang sebenarnya, lalu membangun live model. Jika memilih file SCL, ARSAS membuka configured model tersebut tanpa membuat koneksi live.

03Monitor dan test

Pilih signal, pantau live value, lalu test hanya control yang disetujui.

Mulai cepat dari static DataSet yang ditemukan atau pilih signal secara manual. Live Monitor menampilkan value, quality, dan timestamp; control object tervalidasi muncul pada Command Dock untuk prosedur test yang memiliki otorisasi.

Pertanyaan umum

Apa yang bisa—dan tidak bisa—dibuktikan tester IEC 61850 gratis.

Apakah ARSAS benar-benar gratis dan open-source?
Ya. ARSAS dipublikasikan sebagai software open-source dan download Windows publik tersedia tanpa biaya. Halaman release menampilkan versi, ukuran package dan evidence SHA-256.
Apakah ARSAS bisa dipakai sebagai tester IED untuk FAT dan SAT?
ARSAS mendukung inspeksi IED live, evidence FAT dari IO List yang disetujui, FAT IEC 61850 general, re-verification SAT dan diagnosis commissioning. Procedure serta authority proyek yang disetujui tetap menjadi sumber pengendali.
Apakah ARSAS mensertifikasi interoperabilitas IEC 61850?
Tidak. ARSAS membantu membangun evidence bounded tentang behavior yang diamati—misalnya live model, reporting, GOOSE dan hubungan SCL. ARSAS tidak menggantikan sertifikasi conformance formal atau membuktikan interoperabilitas universal semua vendor.
