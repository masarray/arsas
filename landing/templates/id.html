Mengapa ARSAS berbeda

Dari IED yang reachable menuju evidence engineering yang benar-benar dapat dipakai.

FAT, SAT dan commissioning sering kehilangan waktu untuk memperbaiki file vendor, mapping signal, mencari RCB yang tepat dan membangun ulang konteks device pada aplikasi terpisah.

Workflow terfragmentasi

Integrasi dimulai dari ketidakpastian.

  • Cari atau repair CID/ICD vendor
  • Import file lalu ditolak oleh tool lain
  • Mapping signal dan reporting ulang
  • Kehilangan hubungan value, event dan failure protocol
  • Ulangi setup untuk setiap IED
Workflow ARSAS

Mulai dari device dan pertahankan evidence.

  • Tambahkan IP yang disetujui atau buka SCL yang tersedia
  • Discovery complete live server model
  • Generate IID/ICD atau CID selected-RCB yang bounded
  • Monitor reporting, GOOSE, file dan control dalam konteks IED yang sama
  • Salin exact diagnostic evidence saat workflow gagal
