1

Verifikasi paket Windows

Download installer atau portable single EXE, cocokkan SHA-256, dan baca status Authenticode unsigned. SmartScreen dapat menampilkan peringatan unrecognized publisher.

Verifikasi paket
2

Konfirmasi boundary jaringan

Gunakan hanya jaringan laboratorium, FAT, SAT atau commissioning yang diotorisasi. TCP port 102 diperlukan untuk MMS. Npcap diperlukan untuk capture raw-Ethernet GOOSE dan SMV.

Diagnostic port 102
3

Pilih workspace

Pilih Engineering untuk menambah atau memeriksa IED, atau IO List FAT untuk import sheet legacy, workbook Rev.3 atau project portable. Setelah FAT loaded, perpindahan kembali memakai hide/show tanpa file dialog lain.

4

Buktikan identity signal yang dituju

Di Engineering, periksa IED, reference, value, quality, timestamp dan acquisition source bersama-sama. Di FAT Rev.3, pertahankan exact Event Log Search Reference dan pisahkan dari Report Display Reference.

5

Jalankan workflow bounded

Untuk IO FAT, dapatkan baseline OFF dengan quality baik dan capture sequence OFF → ON → OFF baru. Untuk Engineering live, mulai dari point read-only yang dikenal dan identifikasi apakah acquisition source memakai reporting atau polling sebelum memperluas ke file atau guarded control.

6

Masuk GOOSE atau SMV dari IED card

GOOSE memilih routed capture adapter dan mulai receive-only saat mapping unik. SMV membuka konteks IED terpilih dan capture raw waveform dua siklus. Pemilihan adapter manual tetap menjadi fallback aman.

7

Stop, review dan pertahankan evidence

Pertahankan diagnostic presisi. Stop dan seal session FAT sebelum export Excel, PDF eksekutif atau .arsas. Jangan lakukan active control atau konfigurasi tanpa procedure dan kewenangan eksplisit.
