Controlled FAT sequence

From workbook identity to ordered process evidence.

The first release is deliberately scoped to imported SDI / digital indications. Adapt the external simulation and witness steps to the approved FAT procedure.

01

Import the approved workbook

ARSAS validates the ARSAS_SIGNAL_IMPORT sheet, required headers, project identity, unique TestPointId, IED identity, object reference and expected ON/OFF states. Blocking findings reject the import instead of being guessed.

02

Bind imported points to the live IED

Select the intended imported IED and review whether every enabled point is safely bound to the discovered IEC 61850 signal. Only the selected IED and its imported signals enter the FAT session.

03

Confirm a trustworthy baseline

A good-quality OFF image arms the point for ON. If the point is already ON, ARSAS waits for a new OFF baseline. The first image after reconnect is also baseline only.

04

Capture ON and OFF in order

ARSAS records the new OFF → ON transition and then waits for the matching ON → OFF transition. Duplicate, steady-state and out-of-order observations do not create false evidence.

05

Review evidence quality

Each transition can retain the raw value, normalized state, IED timestamp, independent ARSAS timestamp, quality, acquisition source, monotonic sequence, connection generation, verdict and reason.

06

Stop, seal and export

Stop the IED session before export so the append-only evidence journal can be sealed and verified. Then create Excel, PDF or the complete portable project.

What is not accepted

No false transition from a startup image.

  • Initial ON does not count as ON evidence
  • Reconnect first image does not count as an edge
  • Duplicate or out-of-order observation is ignored
  • Bad or invalid quality is rejected
  • Lost continuity after ON forces review
PASS rule

Two accepted edges in one trustworthy continuity window.

  • Good OFF baseline
  • New OFF → ON transition
  • Accepted ON evidence
  • New ON → OFF transition
  • Accepted OFF evidence captured after ON
Evidence outputs

Use the same project for review, print and continuation.

The approved source workbook remains preserved. Result and handover artifacts are generated separately and protected by explicit identity and integrity checks.

Spreadsheet

Excel result copy

ARSAS copies the approved workbook, matches rows by TestPointId, and writes observed values, IED and ARSAS timestamps, quality, source, ON/OFF verdicts, overall result and state-machine notes. A point mismatch refuses partial output.

Document

Native PDF report

A4 landscape evidence is generated directly by the built-in PDF 1.4 engine with project summary, per-IED sections, wrapped signal rows, timestamps, quality, source, result and reason. No browser, printer driver or third-party PDF layout package is required.

Portable project

.arsas continuation

The project bundles the source workbook, snapshot, sealed evidence journals, Excel result, native PDF, manifest hashes and handover notes. New exports use .arsas; legacy .arsas-iofat filenames remain readable.

Integrity

Verified before restore

ARSAS validates package kind, versions, safe archive paths, size limits, workbook identity, report hashes and the evidence-journal hash chain before continuing the project on another workstation.

Cross-laptop FAT

Carry unfinished work forward without treating restored values as live.

Completed evidence remains preserved, but a new workstation still requires a new trustworthy runtime baseline before unfinished points continue.

A

Laptop A

Import workbook, bind the IED, run the available tests, stop the session and export one .arsas file.

B

Transfer inside the approved project boundary

Keep the project file under the same confidentiality and evidence-handling controls as the source IO List and IED addresses.

C

Laptop B

Choose FAT / IO List Testing → Open ARSAS Project, reconnect and discover the intended IED, then obtain a new baseline.

D

Continue unfinished points

Completed points are excluded by default. Interrupted ON-only continuity is review evidence and is never silently resumed into PASS.
