Sequence FAT terkontrol

Dari identity workbook menuju process evidence berurutan.

Release pertama sengaja dibatasi untuk SDI / digital indication yang diimport. Sesuaikan simulasi eksternal dan witness step dengan procedure FAT yang disetujui.

01

Import workbook yang disetujui

ARSAS memvalidasi sheet ARSAS_SIGNAL_IMPORT, header wajib, identity project, unique TestPointId, identity IED, object reference dan expected ON/OFF. Finding blocking menolak import dan tidak ditebak.

02

Bind point import ke IED live

Pilih IED import yang dituju dan review apakah seluruh point enabled terikat aman ke signal IEC 61850 hasil discovery. Hanya IED terpilih dan signal import miliknya yang masuk session FAT.

03

Konfirmasi baseline terpercaya

Image OFF dengan quality baik membuat point armed untuk ON. Jika point sudah ON, ARSAS menunggu baseline OFF baru. Image pertama setelah reconnect juga hanya baseline.

04

Capture ON dan OFF secara berurutan

ARSAS merekam transition OFF → ON yang baru lalu menunggu transition ON → OFF pasangannya. Duplicate, steady-state dan observation out-of-order tidak membuat evidence palsu.

05

Review quality evidence

Setiap transition dapat menyimpan raw value, normalized state, IED timestamp, ARSAS timestamp independen, quality, acquisition source, monotonic sequence, connection generation, verdict dan reason.

06

Stop, seal dan export

Stop session IED sebelum export agar append-only evidence journal dapat diseal dan diverifikasi. Setelah itu buat Excel, PDF atau project portable lengkap.

Yang tidak diterima

Tidak ada false transition dari startup image.

  • Initial ON tidak dihitung sebagai ON evidence
  • Image pertama reconnect tidak dihitung sebagai edge
  • Observation duplicate atau out-of-order diabaikan
  • Quality bad atau invalid ditolak
  • Continuity hilang setelah ON menjadi review
Aturan PASS

Dua edge accepted dalam satu continuity window terpercaya.

  • Baseline OFF yang baik
  • Transition OFF → ON baru
  • ON evidence accepted
  • Transition ON → OFF baru
  • OFF evidence accepted dan terjadi setelah ON
Output evidence

Gunakan project yang sama untuk review, print dan continuation.

Workbook sumber yang disetujui tetap dipertahankan. Result dan handover artifact dibuat terpisah dan dilindungi oleh identity serta integrity check eksplisit.

Spreadsheet

Copy result Excel

ARSAS menyalin workbook sumber, mencocokkan row melalui TestPointId, lalu menulis observed value, IED dan ARSAS timestamp, quality, source, verdict ON/OFF, overall result serta state-machine notes. Mismatch point menolak partial output.

Dokumen

Report PDF native

Evidence A4 landscape dibuat langsung oleh built-in PDF 1.4 engine dengan project summary, section per IED, signal row yang wrapped, timestamp, quality, source, result dan reason. Tidak membutuhkan browser, printer driver atau third-party package layout PDF pihak ketiga.

Project portable

Continuation .arsas

Project membawa source workbook, snapshot, evidence journal terseal, result Excel, PDF native, manifest hash dan handover notes. Export baru memakai .arsas; filename legacy .arsas-iofat tetap dapat dibaca.

Integrity

Diverifikasi sebelum restore

ARSAS memeriksa package kind, version, safe archive path, size limit, workbook identity, report hash dan hash chain evidence journal sebelum melanjutkan project pada workstation lain.

FAT lintas laptop

Bawa pekerjaan yang belum selesai tanpa menganggap restored value sebagai live.

Evidence yang sudah selesai tetap tersimpan, tetapi workstation baru tetap membutuhkan runtime baseline terpercaya sebelum point yang belum selesai dilanjutkan.

Lanjutkan point yang belum selesai

Point completed dikecualikan secara default. Continuity ON-only yang terputus menjadi review dan tidak pernah diam-diam dilanjutkan menjadi PASS.
