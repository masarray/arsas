Sequence FAT terkontrol

Dari identity workbook menuju process evidence berurutan.

Automatic transition testing sengaja difokuskan pada digital indication SDI yang disetujui. Row unsupported, command, duplicate dan reference tidak lengkap tetap terlihat dan tidak diam-diam diubah menjadi tipe test lain.

01

Import sumber yang disetujui

ARSAS menerima kontrak legacy ARSAS_SIGNAL_IMPORT dan kontrak Rev.3 FAT_Points_Import plus Document_Control. Identity project, endpoint IED, TestPointId, data type, source state text, exact IEC reference, data attribute, functional constraint dan review reason tetap eksplisit.

02

Review readiness tanpa membuat telegram palsu

IED, IP, FC, data attribute atau IEC reference yang hilang tetap blocked. Duplicate key dan active-command point tetap menjadi review scope. Exact Event Log Search Reference dipertahankan untuk korelasi log, sedangkan Report Display Reference hanya dipakai untuk traceability report yang mudah dibaca.

03

Connect dan bind satu IED

ARSAS melakukan discovery model MMS live, menormalisasi wrapper display yang dikenal tanpa fuzzy name guessing, dan hanya menerima satu unique signal match. Progress card mengikuti koneksi, discovery, binding dan acquisition readiness yang nyata.

04

Capture state evidence berurutan

Image OFF dengan quality baik membuat point armed. ARSAS kemudian menerima transition OFF → ON baru dan return ON → OFF pasangannya. Setiap evidence accepted mempertahankan quality, timestamp dan acquisition source; startup, reconnect, duplicate, steady-state atau image out-of-order tidak menjadi edge evidence palsu.

05

Lanjutkan secara aman

Row evidence completed dilindungi sebelum preflight, live preparation dan session start. Pindah ke Engineering hanya menyembunyikan workspace FAT yang loaded; saat kembali, project, selected IED, evidence dan progress yang sama langsung muncul tanpa file dialog.

06

Stop, seal dan export

Stop session aktif, verifikasi append-only journal, lalu export result Excel, PDF eksekutif atau project portable lengkap. Load workbook atau project lain tetap menjadi tindakan replacement yang eksplisit.

Yang ditolak ARSAS

Tidak ada false success dari startup, ambiguity atau identity yang hilang.

  • Initial ON dan image pertama reconnect bukan transition
  • Bad quality dan continuity terputus tetap menjadi review
  • Live-model match ambigu tidak ditebak
  • IEC reference Rev.3 yang hilang tetap blocked
  • Row SAI dan SDO tidak diam-diam dianggap SDI FAT
Aturan PASS

Dua edge accepted dalam satu continuity window terpercaya.

  • Baseline OFF dengan quality baik
  • Transition OFF → ON baru
  • ON evidence accepted
  • Transition ON → OFF baru
  • OFF evidence accepted setelah ON
Output evidence

Gunakan satu project untuk execution, review event log, print dan continuation.

Source yang disetujui tetap dipertahankan. Artifact result dibuat terpisah dengan identity document, signal dan evidence yang eksplisit.

Spreadsheet

Copy result Excel

ARSAS menyalin workbook sumber dan meng-update row test yang cocok tanpa mengubah file asli. Observation, result, event time, log match, evidence reference dan reviewer comment tersedia untuk handover.

Dokumen

PDF eksekutif AS TESTED

Report A4 landscape native memuat konteks project dan supplier, document number, revision, exact IEC 61850/event-log reference, expected state, timestamp relay ON/OFF, result summary, test basis dan area sign-off.

Project portable

Continuation .arsas

Project membawa source workbook, snapshot, journal, report, hash dan konteks handover. Project restore mempertahankan evidence completed tetapi membutuhkan live baseline baru untuk point yang belum selesai.

Integrity

Diverifikasi sebelum restore

Package kind, safe archive path, size limit, workbook identity, report hash dan continuity evidence journal diperiksa sebelum workstation lain melanjutkan project.

Batas stable dan mainline
