Can I learn IEC 61850 here without installing ARSAS?
Yes. The Learning Center explains the mental model, services and common failure patterns in plain language. The software tutorials then show how those concepts appear in a real workstation.
Can ARSAS connect directly to an IED IP address?
Yes when the approved network path and MMS service are available. ARSAS can establish an association, discover the live model and read supported data. Ping alone is not sufficient proof.
Can ARSAS use an approved IO List for FAT?
Yes on the current mainline for imported SDI points. ARSAS requires ordered OFF → ON → OFF evidence and can export Excel, native PDF or a portable .arsas project.
Does ARSAS replace an approved test procedure?
No. ARSAS supports learning and evidence capture, but plant authority, calibrated equipment, protection testing, independent witness and formal acceptance remain separate responsibilities.
