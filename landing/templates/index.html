Now follow the screen

Add IED → choose source → build the model → monitor.

01Choose the source

Click Add IED, then choose live IP or SCL.

Use Discover IED by IP for a reachable relay. Use Open SCL / CID / ICD to inspect a vendor or project model offline; IID and SCD are supported by the SCL workflow too.

02Build the model

Enter the relay IP and run Smart Discovery.

ARSAS connects over IEC 61850 MMS on port 102, reads the real IED identity and builds its live model. If you chose an SCL file, ARSAS opens that configured model without making a live connection.

03Monitor and test

Choose signals, watch live values, then test controls only when the procedure authorizes it.

Start quickly from a discovered static DataSet or select signals manually. Live Monitor shows value, quality and timestamp; validated control objects appear in the guarded Command Dock for authorized test procedures.

SCL in plain language

An engineering model you can inspect before or beside a live connection.

SCL is the IEC 61850 XML language used to describe IED capability and project configuration. ICD usually describes device capability, CID one configured IED, SCD an integrated substation project, and IID an instantiated IED exchange model.

Common questions

What a free IEC 61850 tester can—and cannot—prove.

Is ARSAS really free and open source?
Yes. ARSAS is published as open-source software and the public Windows download is offered at no charge. Release pages expose version, package size and SHA-256 evidence.
Can I use ARSAS as an IED tester for FAT and SAT?
ARSAS supports live IED inspection, approved IO List FAT evidence, general IEC 61850 FAT work, SAT re-verification and commissioning diagnostics. The approved project procedure and test authority remain the governing source.
Does ARSAS certify IEC 61850 interoperability?
No. ARSAS helps build bounded evidence about observed behavior—such as live model, reporting, GOOSE and SCL relationships. It does not replace formal conformance certification or prove universal multi-vendor interoperability.
