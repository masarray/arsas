Before field use

Three useful boundaries.

Can ARSAS connect directly to an IED IP address?
Yes when the approved network path and MMS service are available. A successful ping alone is not proof that the IEC 61850 service path is usable.
Can ARSAS use an approved IO List for FAT?
Yes for the current supported SDI workflow, with ordered OFF → ON → OFF evidence and export to Excel, native PDF or a portable project.
Does ARSAS replace an approved test procedure?
No. ARSAS supports engineering observation and evidence capture; plant authority, calibrated equipment, protection testing and formal acceptance remain separate responsibilities.
