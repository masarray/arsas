Your first IED in ARSAS: from IP or SCL to live monitoring.

ARSAS is a Windows IEC 61850 workstation. Add a live relay by its approved IP address, or open an SCL engineering file—ICD, CID, IID or SCD—when you need to inspect the model offline before connecting.

Three visible steps

Use the same controls you will see in the application.

The screenshots are shown at their original aspect ratio. Open any image full size when you need to read the interface detail.

01Add the IED

Choose a live relay or an SCL model.

Click Add IED. Select Discover IED by IP for a live relay. Select Open SCL / CID / ICD for an offline engineering model; the SCL workspace also accepts IID and SCD.

02Discover safely

Enter the approved relay IP address.

Keep MMS port 102 unless the project explicitly specifies another endpoint. Select Connect & Discover; ARSAS reads the real IED identity, DataSets, RCBs and live model through the production Smart Discovery path.

03Monitor or test

Start monitoring, then expose only validated controls.

Choose Static DataSet for a fast report-ready path, or Select Signals for manual selection. Review value, quality and timestamp in Live Monitor. Use the Command Dock only for validated control objects under an approved test procedure.

Before field work

Keep the first connection safe and attributable.

The visual path above gets you started. Use this checklist before expanding into FAT, GOOSE, SMV, files or active control.

1

Verify the Windows package

Download the installer or portable single EXE, compare SHA-256, and review the unsigned Authenticode status. SmartScreen may show an unrecognized publisher warning.

Verify package
2

Confirm the approved network boundary

Use only the authorized laboratory, FAT, SAT or commissioning network. TCP port 102 is required for ordinary MMS. Npcap is required for raw-Ethernet GOOSE and SMV capture.

Port 102 diagnostics
3

Choose the workspace

Select Engineering to add or inspect an IED, or IO List FAT to import the legacy sheet, Rev.3 workbook or portable project. Once FAT is loaded, switching back and forth uses hide/show without another file dialog.

4

Prove the intended signal identity

In Engineering, inspect IED, reference, value, quality, timestamp and acquisition source together. In Rev.3 FAT, preserve the exact Event Log Search Reference and keep the readable Report Display Reference separate.

5

Run the bounded workflow

For IO FAT, obtain a good OFF baseline and capture a new OFF → ON → OFF sequence. For live Engineering, begin with a known read-only point and identify whether its acquisition source is reporting or polling before expanding to files or guarded control.

6

Enter GOOSE or SMV from the IED card

GOOSE resolves the routed capture adapter and starts receive-only capture when unique. SMV opens the selected IED context and captures a bounded two-cycle raw waveform. Manual adapter selection remains the safe fallback.

7

Stop, review and preserve evidence

Retain exact diagnostics. Stop and seal the FAT session before exporting Excel, executive PDF or .arsas. Do not perform active control or configuration work without explicit procedure and authority.
